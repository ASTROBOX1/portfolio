```

Skills:             4 equal columns
Padding:            64px vertical, 32px horizontal (desktop)
```

### Animations
```
Fade + Slide Up:    opacity 0→1, y 40→0, 0.8s ease-out
Stagger Delay:      100-150ms between children
Hover Lift:         translateY(-12px), 300ms ease
Scroll Trigger:     When element enters viewport (30% visible)
```
